## Ресурси

Peak RSS включає нативні бібліотеки та імпорти. Payload, build time і час запитів подано окремо. Raw timings містять три повтори; вони не є оцінкою промислової реалізації.

## Обмеження

Шість кандидатів — обмежений пошук, не оптимум. Перенесення параметрів 2D→3D явне. SDF/projection API counts не вимірюють усі аналітичні операції проєктора. Три роздільності не доводять збіжності. Тонкий тор залишається складним навіть для еталона. Повна літературна перевірка новизни не виконана.

## Відтворення

`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 ../.venv/bin/python run_extended.py` з папки CompactKernelResearch.

`protocol.json`, `selection.json`, CSV/JSON у results/extended містять усі конфігурації, відмови, лічильники, хеші коду й версії. `--resume` дозволений лише за незмінних хешів.
