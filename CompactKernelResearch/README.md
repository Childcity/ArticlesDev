# Дослідження компактного псевдогаусового ядра

Три чисельні експерименти для пунктів 1–3 з [аналітичної записки](../CompactKernelResearch.md). Код і пояснення українською; короткі підписи графіків англійською для переносимості шрифтів.

## Запуск

З кореня репозиторію (Python 3.12):

```bash
python -m venv .venv
.venv/bin/python -m pip install -r CompactKernelResearch/requirements.txt
cd CompactKernelResearch
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 ../.venv/bin/python -m pytest -q
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 ../.venv/bin/python generate.py
../.venv/bin/python -m streamlit run app.py --server.address 0.0.0.0
```

Відкрити адресу Streamlit (типово порт 8501; у хмарі потрібне перенаправлення порту). Вибрати експеримент, змінити параметри й натиснути **Обчислити**. Для пункту 3 є окрема кнопка запуску всіх серій. Для 3D доступні зрізи й об’ємні ізоповерхні; роздільність інтерактивної 3D-оцінки обмежена 51³. На критичних рівнях цього може бути недостатньо для правильного відображення тонких деталей.

## Файли й результати

- `core.py`: точне авторське ядро, розріджена колокація, аналітичні SDF.
- `experiment1.py`: відтворення константи/афінної функції, покриття, SVD, граничний запас.
- `experiment2.py`: чотири 2D-форми, сфера й тор, поле, знак і компоненти офсетів.
- `experiment3.py`: незалежна зміна факторів, сталий фізичний радіус, критичні офсети.
- `tests/test_experiments.py`: математичні, геометричні й обчислювальні перевірки.
- `results/results.json`, CSV: вимірювання та фактичні версії середовища; PNG/PDF: графіки.
- `Experiment1.tex`, `Experiment2.tex`, `Experiment3.tex`, `NextStep.tex`: автономні українські звіти. Відтворюються командою `generate.py` через `reports.py`.
- `source/`: зображення авторських поліномів, експортовані з WMF у DOCX. Для n=1 це формула (2), для n=2,3,4 — (3),(4),(5). Імена збережено за проміжним експортом, відповідність див. `source/README.md`.

Для складання звітів потрібні XeLaTeX і шрифт DejaVu Serif. Запускати в цій папці:

```bash
xelatex -interaction=nonstopmode -halt-on-error Experiment1.tex
xelatex -interaction=nonstopmode -halt-on-error Experiment2.tex
xelatex -interaction=nonstopmode -halt-on-error Experiment3.tex
xelatex -interaction=nonstopmode -halt-on-error NextStep.tex
```

Базова інтерполяція не містить прихованого згладжування, нормування суми або поліноміального доповнення. Тому її похибки є результатами дослідження. Сингулярні випадки фіксуються як відмови. Повний ранг обчислюється лише для малих матриць (до 900 центрів); для більших інтерактивний звіт вказує `null`.

Результати — початкові діагностичні серії з seed=0, без висновків про універсально найкращі параметри. RMSE смуги та помилка знака не є відстанню Гаусдорфа між поверхнями. Компоненти визначаються на сітці зі зв’язністю по осях; тонкі еталонні тіла теж можуть дискретно розпадатися. Наступні перевірки описано в `NextStep.tex`.
