# Псевдогаусова інтерполяція зі статті: експерименти 1–6

**Стан на 2 листопада 2026.** Пункти 1–3: `article-isolines-v3`; extended-експерименти 4–6: `extended-4-6-n4-v1`. Для псевдогаусового підходу в extended-протоколі стандартна гладкість **n=4**, тобто `φ(q)=(1−q²)_+⁵`. Добираються радіус підтримки та крок ізоліній. Код реалізує запропонований у DOCX вибір точок на найближчих ізолініях SDF та парне порівняння `grid` / `isolines`.

## Запуск

З кореня репозиторію, Python 3.12:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r CompactKernelResearch/requirements.txt
cd CompactKernelResearch
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 ../.venv/bin/python -m pytest -q
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 ../.venv/bin/python generate.py
../.venv/bin/python -m streamlit run app.py --server.address 0.0.0.0
```

Сервер запускається лише останньою командою. Змінюйте стратегію вузлів, `h`, `ρ=r/h`, порядок (типово `n=4`), `Δ/h`, поворот, зсув та офсет і натискайте **Обчислити**. Сторінка 2 також має приклади за схемою рисунків 4–6/8, сторінка 3 — повну парну серію. 3D-роздільність інтерфейсу обмежено 51³; тонкі офсети вимагають значно густішої сітки для правильного відображення.

## Що саме відповідає статті

Основне джерело — опублікований `papers/2025_Pseudo_Gaussian_Modeling/pseudo_gaussian_grid_ric_formatted (2).docx`. Його SHA256 збережено в `results/results.json`.

- `core.kernel()` — поліноми (2)–(5): `(1-s²/r²)_+^(n+1)`.
- `geometry.Geometry.project_level()` — найближча точка заданого рівня точної SDF для шести еталонних геометрій.
- **`core.select_isoline_nodes()` — запропонований вибір точок:** за незмінних центрів `c_i` знайти найближчу точку серед рівнів `d=qΔ`, `q` ціле, `0<Δ≤h`, із відстанню до свого центра меншою за `r`.
- `core.fit(..., strategy='isolines', level_step=...)` — знайти коефіцієнти з умов інтерполяції в обраних точках. `strategy='grid'` дає контрольний варіант зі статті.
- `core.Model.evaluate()` — зважена сума радіальних функцій, рівняння (8)/(12). Точки інтерполяції не потрібні для оцінювання готового поля.

Вибір рівня не зведено до `round(d/Δ)`: біля медіальних множин це може бути не найближча ізолінія. Перебираються всі рівні, які через 1-ліпшицевість SDF можуть дати вузол усередині підтримки. Проєкції враховують кути, перетини офсетних дуг і порожні рівні. Незалежні геометричні тести зіставляють їх із густими контурами SDF та параметричними 3D-поверхнями.

Правила неєдиної проєкції та чисельні допуски явно задано в коді/звітах: при рівній відстані вибирається менший рівень, у геометричній проєкції — детермінований напрям. Збіг вузлів (перевірка після округлення до 11 знаків) і надмірний вузловий залишок фіксуються як відмови. Немає прихованого згладжування, нормування суми, регуляризації чи розсування вузлів. Малий залишок не гарантує хорошого геометричного результату або малої обумовленості.

`strategy='random'` залишено лише як явний допоміжний режим для діагностичних тестів; експерименти, звіти й інтерфейс його не використовують.

## Експерименти та результати

1. `experiment1.py`: порівняння вибору вузлів, покриття, рангу/обумовленості, SDF кола. Константа й афінна функція — окремі діагностичні праві частини на вузлах, вибраних за SDF; вони не трактуються як SDF.
2. `experiment2.py`: коло, повернутий квадрат, два диски, багатокутниковий перешийок, сфера й тор. Парні результати, вузли на рисунках, нульові контури, справжні 3D-ізоповерхні. Сфера й тор — наше розширення, а не приклади зі статті. Окремі випадки 13×13 використовують `Δ=0.25` і `0.081384`.
3. `experiment3.py`: 88 конфігурацій (44 пари), незалежна зміна факторів, зокрема `Δ/h`, сталий фізичний `r` і критичні офсети. Базові умови повторюються між серіями; це не незалежна статистична вибірка. Додано чисельний добір `Δ` за схемою обговорення рисунка 8: RMSE на 512 Sobol-точках, грубий пошук і локальне уточнення, після чого окрема перевірка на сітці 151².

`results/` містить актуальні CSV/JSON, графіки PNG/PDF і лог тестів. `Experiment1.tex`, `Experiment2.tex`, `Experiment3.tex`, `NextStep.tex` та відповідні PDF містять формули, поточні вимірювання й обмеження. Числа в звітах генеруються з результатів поточного запуску; попередні висновки не копіюються.

RMSE смуги вимірює поле, а не положення поверхні. `sampled_offset_hausdorff` — двосторонній максимум відстаней між вершинами дискретних ізоповерхонь, без гарантії для неперервних поверхонь. `model_surface_sdf_error` перевіряє точну SDF на вершинах модельного рівня. Компоненти рахуються зі зв’язністю по осях; дискретні тонкі еталонні тіла також можуть розпадатися. Вироджені/порожні рівні не отримують вигаданого нульового значення відстані.

## Межі відтворення рисунків

Відтворено математичний спосіб побудови інтерполянта й вибору точок. Для рисунків статті не вказано однозначно всі `r`, `n`, точний розмір квадрата та другий кут. У прикладах 13×13 явно вибрано `h=.25`, `r=.5` та `r=1`, `n=4`, півсторону `.85`, кути `45°` і `35°`. `r=1,n=4` наведені у статті для ілюстрації базисної функції на рисунку 2, але їх використання у кожному іншому рисунку не підтверджене. `r=.5` залишено як контроль чутливості. Це приклади за схемою статті, **не точне відтворення її числових результатів або оптимуму `Δ=.081384`**. Значення `.081384` використане як контрольне, а не оголошене універсальним оптимумом.

Висновок про перевагу стратегії не задається наперед: зберігаються випадки покращення й погіршення, похибки й відмови. Пункти 4–6 аналітичної записки залишаються актуальними; оновлений стан описаний у `NextStep.tex`.

## Добір кроку та збереження поля

На сторінці 3 кнопка **Добрати крок ізоліній: приклад за схемою рисунка 8** запускає калібрування для квадрата під 35° (`h=.25`, `r=1`, `n=4`, півсторона `.85`). Ця кнопка має фіксований документований приклад; для довільних параметрів використовуйте Python API `experiment3.optimize_level_step(...)`. Критерій — RMSE SDF у всій області на 512 scrambled Sobol-точках (seed 2026). Пошук у `[.15h,h]`: 17 грубих кандидатів, контрольні `h/2` і `.081384` та локальне уточнення трьох найкращих околиць. Перевірочна сітка 151² не бере участі в доборі. Всі спроби, включно з відмовами, записуються в `results/optimization_trials.csv`.

Норма похибки, алгоритм пошуку та точні умови авторського оптимуму в статті не задані повністю. Тому отриманий крок не оголошується відтворенням числа `.081384` або глобальним оптимумом. Налаштування й перевірка на тій самій формі дають просторову перевірку, а не доказ перенесення на нову геометрію.

`storage.from_model(model).save(path)` записує один коефіцієнт на центр, початок/крок/форму регулярної сітки й глобальні `r,n`. `storage.load(path)` відновлює поле без вихідної SDF та точок інтерполяції. `results/optimized_field.npz` — готовий приклад; у Streamlit його можна завантажити після оптимізації. NPZ — технічний вибір цієї реалізації, а не новий формат зі статті. Розміри масивів коефіцієнтів і значень воксельної SDF однакові за тієї самої точності; стиснені архіви та пікова пам’ять побудови можуть відрізнятися.

Точна карта «твердження/формула статті → код → перевірка» знаходиться в [ArticleAlignment.md](source/ArticleAlignment.md).

## Extended-експерименти 4–6 (2 листопада 2026)

Відтворюваний протокол `extended-4-6-n4-v1` та результати описано в [ExtendedResearch.md](ExtendedResearch.md). Псевдогаусове ядро має фіксовану гладкість **n=4**; радіус і крок рівнів добираються лише на навчальних формах. Методам із вузлами сітки задано шість радіусів `ρ=1.25,1.5,2,2.5,3,4`; для isolines — шість пар із `ρ=1.5,2,3` та `Δ/h=0.5,1`. Після редагування джерел потрібен повний запуск. `generate.py` відтворює пункти 1–3 та їхній NextStep; для актуального підсумку всіх пунктів запускайте `run_extended.py` **після нього**. Обчислення виконуються на CPU. Час залежить від машини; стадія ресурсів використовує ізольовані процеси й обмеження 180 с на конфігурацію. Timeout та інші відмови записуються в дані.

### Що перевірено

| Пункт | Реалізація й фактичний обсяг |

| 5: геометрія | `experiment5.py`, `quality.py`: три роздільності на те саме поле, похибки градієнта/ейконалу/напряму нормалі, цифрові Betti-числа та перетин межі області. Перевірено кути, перешийки, злиття дисків і отвір/тонку трубку тора. |

Дев’ять методів: `pg_grid`, `pg_isolines`, `wendland_c2_grid`, `wendland_c2_isolines`, `wendland_c4_grid`, `wendland_c4_isolines`, `linear`, `cubic`, `cubic_redistance`. Останній — окрема сіткова baseline: оцінка cubic на сітці h/2, знаковий EDT і лінійна інтерполяція. Її додаткова пам’ять та дрейф поверхні враховані.

Capsule (стадіон) і rounded box — нові аналітичні SDF, яких не було в доборі. Інші held-out форми — два диски, перешийок, сфера й тор. Добір проводиться в 2D, а перенесення його параметрів у 3D оцінюється явно; це не окремий оптимальний підбір для 3D. У кожній задачі однакові область, float64, центри й запас 4h.

### Візуалізації

У Streamlit додано сторінки **4. Незалежна перевірка**, **5. Градієнти та топологія**, **6. Парето та ресурси**. На сторінці 5 можна змінити форму, метод, роздільність і офсет та повторно обчислити метрики. Сторінки 4/6 фільтрують збережені відтворювані результати; ресурсні серії не запускаються автоматично під час відкриття апки.

### Як читати метрики

- `band_rmse` — похибка поля, `sampled_offset_hausdorff` — двостороння відстань між хмарами вершин витягнутих рівнів. Це не доведена відстань Гаусдорфа неперервних поверхонь.
- Градієнт компактних сум аналітичний. Для еталонної SDF використано дві центральні різниці та чисельну маску локальної регулярності. Маска відкидає нестабільні/неодиничні градієнти, але не є повним аналітичним описом медіальної осі. Для grid-методів похідні теж чисельні.
- Betti b0/b1/b2 розрізняють компоненти, отвори й порожнини. Використано foreground 4/6 та background 8/26. `touches_boundary` попереджає про обрізання області. Тонкий тор може лишатися недорозділеним навіть при 65³.
- Середні/медіани за офсетами не є незалежними статистичними спостереженнями. Seed min/max — діапазон медіан трьох seeds, а не довірчий інтервал.
- Карта відмов використовує наперед заданий поріг H>0.1 або відмінність цифрової топології. `quality_threshold` — screening на 101², не доказ непридатності методу. Покриття, чисельний ранг та алгебраїчні відмови записані окремо.
- SDF API counts та projection calls/points не прирівнюються за вартістю: внутрішня аналітична робота проєктора відрізняється. У tuning time враховано всіх кандидатів, включно з невдалими. Однаковий максимум кандидатів не означає однакової кількості інформації про геометрію.
- `stored_bytes` — мінімальний числовий payload готового поля, без координат регулярної сітки та без кешу LU. `peak_rss_bytes` — абсолютний максимум процесу з нативними бібліотеками та імпортами. Нульовий приріст від імпортного baseline не означає нульової пам’яті алгоритму. Окремо є `editing_peak_rss_bytes` і обсяг числових факторів L/U/перестановок.
- `cached_update_seconds` — нова SDF за фіксованих початкових вузлів і з повторним використанням факторизації. Для isolines це вже не новий адаптивний вибір вузлів. `full_rebuild_seconds` включає перевибір вузлів. Якість обох режимів збережена.
- `total_seconds[B]` — build+B×query(8192); `total_edit_seconds[B]` — cache_prepare+B×(cached_update+query). Добір параметрів оплачується окремо. Час є характеристикою цих Python/SciPy реалізацій і цієї машини.

`results/extended/` містить `training`, `selection`, `holdout`, `by_shape`, `resolution`, `failure_map`, `resources`, `summary`, протокол/версії та графіки PNG/PDF. Докладні формули, таблиці та обмеження — в `Experiment4.tex`–`Experiment6.tex`; короткий поточний підсумок — у `NextStep.tex`.

Ресурсні геометрії фіксовані: capsule у 2D та torus у 3D, кут 47°, зсув 0.01. Це дозволяє порівнювати методи на тій самій задачі, але ресурсна серія не охоплює всі held-out форми. У raw config `order=4` задає стандартну гладкість `pg_*`; для Wendland гладкість визначається сімейством C²/C⁴, а для grid-схем цей параметр не використовується.

`editing_peak_rss_bytes` — накопичений high-water RSS на момент завершення редагування. Він включає попередні етапи цього процесу, зокрема оцінювання якості, тому **не є ізольованим приростом пам’яті лише операції редагування**. Основний `peak_rss_bytes` знято раніше, після побудов і серій запитів, до витягування поверхонь. Числові обсяги L/U також не описують усіх службових буферів бібліотеки.

## Підсумок extended-серії при n=4

Для обох псевдогаусових стратегій добір обрав `ρ=2`; для isolines — `Δ/h=0.5`. Медіанна RMSE смуги `pg_grid` / `pg_isolines`: **0.01353 / 0.01465** у 2D та **0.01946 / 0.04961** у 3D. Найменшу медіанну RMSE серед перевірених методів дали Wendland C² grid у 2D і Wendland C⁴ grid у 3D. Це висновки для заданих форм, кандидатів і бюджетів, а не універсальний рейтинг.

Карта при n=4 містить 40 конфігурацій: 13 — у межах заданого порогу, 19 — з прапорцем якості, 8 — з непокритими підтримками точками. Порогові прапорці не замінюють доведення геометричної коректності. Детальні результати та графіки наведено в `Experiment4.pdf`–`Experiment6.pdf` і `results/extended/`.
